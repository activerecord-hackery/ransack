# Community and support

## Questions and bugs

* Questions and discussion belong in
  [GitHub Discussions](https://github.com/activerecord-hackery/ransack/discussions),
  where a wider community can help.
* File an [issue](https://github.com/activerecord-hackery/ransack/issues) if a
  bug is caused by Ransack, is new (has not already been reported), and _can be
  reproduced from the information you provide_.
* A pull request with a failing test that demonstrates the problem is the best
  bug report of all.

Before filing an issue or a pull request, read the
[Contributing Guide](https://github.com/activerecord-hackery/ransack/blob/main/CONTRIBUTING.md).

## Security

To report a security vulnerability, use the
[Tidelift security contact](https://tidelift.com/security). Tidelift will
coordinate the fix and disclosure. See the
[Security Policy](https://github.com/activerecord-hackery/ransack/security/policy)
for supported versions.

## Supporting Ransack

* Support the project on [Open Collective](https://opencollective.com/ransack).
* Use Ransack in your apps, and tell us when something is broken or missing.
  A failing spec to demonstrate the issue is awesome; a pull request with
  passing tests is even better.
* Spread the word if Ransack has been useful to you. The more people use it,
  the quicker bugs are found and fixed.
